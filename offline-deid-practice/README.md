# 離線去識別化練習工具

## 使用方式

1. 在 Windows 檔案總管中雙擊 `index.html`。
2. 請只輸入合成案例、公開資料，或已依機關規範核准的資料。
3. 按「掃描可能風險」，確認紅色與黃色提示。
4. 選取要處理的項目，按「套用選取處理」。
5. 完成 4 項人工複核，才將處理結果作為外部 AI 的教學素材。

## 離線與安全設計

- 本工具沒有伺服器、帳號、分析追蹤或第三方程式庫。
- 所有處理均在開啟頁面的瀏覽器內執行；關閉頁面後，文字不會由本工具保存。
- 工具的掃描結果只是第一輪提醒。沒有被標示的文字，仍可能造成間接識別。

## 目前能偵測的線索

- 身分證字號、電子郵件、臺灣手機號碼、市話、常見精確地址格式、姓名欄位。
- 精確日期、年齡、部分家庭或健康敏感描述、教育機構與班級線索。

## 教學上的正確說法

請向學員說明：「這個工具協助我們找線索；去識別化是否足夠，仍需由熟悉資料與業務情境的人完成判斷。」

## 未來可升級的本機 AI 版本

若中心日後同意在指定電腦安裝本機模型，可將中文命名實體辨識模型（如 CKIP 或 HanLP）及自訂臺灣個資規則加入流程。不過，模型偵測仍須保留人工覆核，且應先以合成測試資料驗證準確率。
