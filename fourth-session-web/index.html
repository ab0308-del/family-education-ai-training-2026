06 · 全課共用

每個工作都走同樣四步

  1. 說清楚：目標、資料在哪、存到哪、什麼格式
  2. 先預覽：要求先做 2–3 筆或先給計畫，「等我確認」
  3. 再批次：確認沒問題，才全部執行
  4. 自己驗收：開檔案抽查，AI 沒有把握的標「待確認」
日期、人名、數字缺少時，請 Agent 標「待確認」，不要自己補。
01

WORK 01 · RESEARCH

蒐集家庭教育公開資訊

搜尋來源Word

08 · 工作一

找到可信的公開資料，留下來源再使用

情境

下個月要辦親子活動，想先了解其他縣市家庭教育中心、教育部公開頁面有哪些可參考的主題與作法。

Agent 要做的事

搜尋公開資料，整理成「資源介紹＋來源＋網址＋查詢日期」，存成 Word，再草擬一份活動構想。

完成後看看：點開幾個網址核對內容；找不到來源的內容不要使用。

09 · 直接貼上

先看大綱，確認後才往下做

我要為家庭教育中心規劃一場【親子情緒管理】活動。請建立一個叫「家庭教育資訊」的資料夾，這次搜尋到的資料和製作的檔案，都放在這個資料夾裡。
1. 請搜尋臺灣【教育部家庭教育網、各縣市家庭教育中心】等公開網頁中，與【親子情緒管理】有關的資源（講座、活動、文章、影片）。整理資源名稱、一句話介紹、來源單位、網址、查詢日期，存成 Word，檔名為「公開資訊整理」。
2. 只使用公開網頁，不要把網頁內容整段照抄；找不到來源的內容請標「來源待確認」。
3. 再根據整理結果，草擬一份活動構想，包含活動名稱、對象、目標、活動流程（約 2 小時），存成 Word，檔名為「活動構想」。日期、地點、預算等沒有資料的欄位請寫「待確認」，不要自己補。
做到這裡先停下來，把你的整理重點告訴我，等我確認後再繼續。

WORK 02 · IMAGE

把爬文成果做成宣傳圖

文案生圖可編修

11 · 工作二

先寫文案，再生圖，文字另外放

承接工作一

使用「活動構想」的內容，不重新找資料。

為什麼文字另外放？

AI 生成圖片裡的中文字容易出錯。圖片不放字，文字放在文件上，才能自己修改。

完成後看看：活動名稱、日期、地點是否正確？待確認的欄位是否仍標示「待確認」？

12 · 直接貼上

先看文案，再生兩張不同風格

請根據「家庭教育資訊」資料夾裡的「活動構想」，製作一張活動宣傳圖，對象是【國小中高年級的家長與孩子】。
1. 先寫宣傳文案：主標題（12 字以內）、副標題、三個活動亮點、報名方式。日期、地點、報名網址若「活動構想」裡是「待確認」，文案也要保留「待確認」，不要自己補。做到這裡先給我看文案，等我確認。
2. 我確認後，使用生圖工具，產生兩張不同風格的宣傳圖（例如：溫暖水彩風、簡潔扁平風）。圖片裡不要有文字，留出放標題的空白位置。
3. 把文案與其中一張圖，做成一頁 A4 的 Word 宣傳單，文字要能直接編輯。存入「家庭教育資訊」資料夾，檔名為「活動宣傳單」。
最後告訴我完成了哪些檔案，以及哪些資訊仍是待確認。

WORK 03 · ASSISTANT

Agent 當活動行政助理

下載解壓縮盤點

15 · 工作三

把一包資料交給助理，先盤點再使用

情境

承辦人收到一包雲端硬碟的活動資料：檔案多、名稱亂、不知道從哪開始看。

安全原則

不修改、不刪除原始素材；遇到同名檔案另外保留；讀不了的檔案要說明，不要猜內容。

這一步取得的素材，會用在工作四和工作五。

16 · 直接貼上

下載、解壓縮，並做素材盤點表

請幫我下載這個 Google Drive 資料夾裡的研習素材：
https://drive.google.com/drive/folders/1MFW5eyvNXyBgLXNe8ImI3aKNopK9dOkH?usp=share_link
1. 在目前的專案資料夾裡，建立「研習素材」資料夾，把下載的檔案放進去；如果有壓縮檔，請解壓縮，並保留原始壓縮檔。
2. 幫我整理一份「素材盤點表」，列出檔名、檔案類型、大小，以及一句話的內容摘要，存成 Excel。
3. 不要修改或刪除原始素材；如果遇到同名檔案，請另外保留，不要直接覆蓋。
4. 最後告訴我下載了哪些檔案，有沒有無法下載、解壓縮或讀取的檔案。無法讀取的內容請註明，不要猜測。

WORK 04 · FILES

名單＋範本，做出學員名牌

ExcelWord套印

18 · 工作四

讓 Agent 讀名單，套進名牌範本

兩個檔案

學員名牌名單_虛擬資料.xlsx：20 位虛構學員。
學員名牌範本.docx：有「家庭教育中心」字樣與配色的名牌版面。

你要驗收的

姓名、組別、職稱有沒有放對位置？名單有問題的人，Agent 有沒有先告訴你，而不是自己補？

名單裡刻意放了一些小問題（重複、缺資料、名字特別長），看看 Agent 能不能找出來。
名單為虛構資料。講師可先請學員猜：名單裡藏了哪三種問題？重複的蔡宜庭、缺職稱的江澄、四個字名的歐陽心悅與趙一二三。

19 · 直接貼上（1/2）

先檢查名單，再做三張樣本

請讀取資料夾中的「學員名牌名單_虛擬資料」Excel 和「學員名牌範本」Word，依照名單製作學員名牌，保留範本原本的版面、配色與「家庭教育中心」字樣。
1. 先檢查名單：列出重複的姓名、缺少的欄位、名字太長可能放不下的人。有問題的資料先不要自行補填或刪除。
2. 用資料完整的前 3 位學員製作名牌樣本，存成 Word 和 PDF，讓我檢查。做到這裡先停下來，等我確認。

20 · 直接貼上（2/2）

確認樣本後，再批次、排版成可列印

3. 我確認後，再批次製作全部學員的名牌。每張 A4 排 8 張名牌（2 欄 4 列），名牌之間留裁切線，存成 Word 和 PDF，放進「名牌成品」資料夾。
4. 名單中的重複姓名，請先問我要保留哪一筆，不要自己決定。缺少職稱的人，名牌上請寫「職稱待確認」。
5. 最後告訴我完成幾張名牌、共幾頁，並列出沒有製作或需要我確認的名單與原因。

WORK 05 · PHOTOS

讓 Agent 讀懂照片，再分類與命名

看懂畫面分類命名

22 · 工作五

照片分類的前提，是 AI 先讀懂畫面

情境

旅行回來，資料夾裡有一堆沒有命名的照片，想依地點與內容整理好。工作三下載的素材包裡就有這批照片。

資料安全

只用課程提供的旅遊照片練習。照片一律用「複製」整理，原始檔保留不動；日後整理自己的照片，也要先確認內容能不能交給 AI。

完成後看看：原始照片還在嗎？抽查三張的分類、檔名、日期是否和畫面相符？

23 · 直接貼上（1/2）

先盤點、先提分類方式，不要動檔案

請幫我整理「旅遊照片」資料夾裡的照片。
1. 先盤點照片，告訴我打算怎麼分類，以及有哪些需要注意的地方。先不要更動檔案，等我確認後再整理。
2. 分類時，請參考照片的拍攝時間、GPS 位置、檔名和畫面內容。沒有拍攝資訊或無法確定地點的，不要自行猜測。
3. 我確認後，只用「複製」的方式，把照片放進新的「旅遊照片整理」資料夾，保留所有原始檔案。

24 · 直接貼上（2/2）

分類、改名、挑封面，再做整理報告

4. 新資料夾內分成：01_交通、02_海邊、03_景點、04_美食、05_人物、06_夕陽、07_住宿、08_夜景、09_精選封面、10_需要確認。每張照片先選一個最適合的分類，適合當封面的可以另外複製一份到「09_精選封面」。
5. 模糊、疑似重複、太暗或無法確定分類的照片，放進「10_需要確認」，不要刪除。
6. 複製後的照片改名為「景點名稱＿日期＿序號＿描述」，保留原本的副檔名。無法確認的地點或日期，請標示「地點待確認」或「日期不明」。
7. 最後做一份整理報告，告訴我原本有幾張、整理後有幾張、各資料夾的張數，以及哪些照片需要我確認。封面額外複製的張數請另外列出。
請先回報盤點結果、整理方式和注意事項，等我確認後再執行複製與改名。

25 · 選做

進階：把封面照片做成短片腳本

先做的人

請 Agent 依「09_精選封面」照片，寫一份 30 秒短片腳本：每張照片停留幾秒、配一句字幕、需要什麼配樂風格。

提醒

這是進階選項，不需要每個人完成。先看腳本合不合理，再決定要不要真的製作影片。

已經完成的人也可以回頭挑戰：請 Agent 把工作一、二的內容，整理成一頁活動新聞稿。
