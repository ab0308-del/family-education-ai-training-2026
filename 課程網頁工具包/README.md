# 第一堂 AI 培力課網頁工具包

## 開啟方式

- 雙擊 `index.html`：開啟網頁簡報。
- 雙擊 `wordwall.html`：開啟問卷第 12、13 題的離線文字牆。

## 簡報操作

- 鍵盤左右鍵、Page Up / Page Down 或空白鍵換頁。
- Home / End 跳到開頭或最後一頁。
- 下方中間的標題可開啟頁面目錄。
- 右下角按鈕進入全螢幕。

## 文字牆操作

1. 從 Google 表單回應試算表複製第 12 題的回答整欄，貼入左側。
2. 複製第 13 題的回答整欄，貼入右側。
3. 按「生成文字牆」。
4. 可全螢幕投影、重新排列，或列印／儲存為 PDF。

## 資料安全

兩個網頁不需網路。文字牆貼入的內容僅在當前頁面的記憶體處理，不會上傳、寫入檔案或儲存到瀏覽器。關閉或重新載入頁面後，貼入內容即消失。投影前仍應人工檢查姓名、個案細節及其他可間接識別資訊。
